Rule of thumb

4-bit takes about 0.6GB per billion parameters; 8-bit about 1.1GB. Those figures cover weights only, so leave room for context and the OS.

Mixture-of-experts

An MoE model needs memory for all its parameters but runs at the speed of the few active per token. That’s why most big models today are MoE.

The macOS memory cap

macOS lets the GPU use roughly two-thirds to three-quarters of unified memory by default. You can raise it with sudo sysctl iogpu.wired_limit_mb=….

Data center GPUs

The 🏢 line counts 80GB H100s (A100s are the same size) and ~180GB B200s needed to hold 8-bit (FP8) weights, using 90% of each card. Real deployments round up to 2, 4, or 8 GPUs per server and want spare memory for long contexts and many users.

Comparable Claude model

Names the Claude model you’d reach for to do the same kind of task. It isn’t a claim of equal performance; open models still trail on harder versions of these tasks.

About popularity

A rough three-step signal based on OpenRouter token usage and Hugging Face downloads. Big models are judged mostly by API traffic; small ones mostly by downloads.
